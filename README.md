# Entity.Http.Rpc

`Entity.Http.Rpc` is an HTTP RPC support package for the Entity server framework. It provides reusable infrastructure for service-to-service communication and modular backend integration in .NET applications.

## Features

- HTTP-based RPC support for Entity services
- Reusable integration infrastructure for modular server components
- Designed for backend and game server service communication
- Multi-targeted for `net8.0`, `net9.0`, and `net10.0`

## Installation

```bash
dotnet add package Entity.Http.Rpc
```

## Usage

Add the package to your Entity-based server project and configure it as part of your service communication layer.
